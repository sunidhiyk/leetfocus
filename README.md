# 🍅 LeetFocus

A Chrome extension that **automatically saves your LeetCode progress** and keeps you focused with a **Pomodoro timer**.

- **Auto-logging.** When a submission is *Accepted*, LeetFocus saves the problem number, title, difficulty, topics, language, runtime/memory percentiles, how long you spent on it, and how many wrong attempts came first.
- **Pomodoro timer.** Focus, short-break, and long-break cycles with a live countdown on the toolbar badge, desktop notifications, and optional auto-start.
- **Floating timer on problem pages.** A small draggable timer sits on top of LeetCode with start/pause/skip and "time on this problem". It can shrink to a progress ring, remembers where you put it, follows LeetCode's light/dark theme, and can be turned off in Settings.
- **Daily goal.** Set a target for problems and/or pomodoros per day (default 3 + 4). You get progress bars in the popup and dashboard, a one-time "goal reached" notification, a goal streak, and goal days marked on the heatmap. Each day remembers the goal it had, so changing your goal doesn't rewrite past streaks.
- **Spaced-repetition reviews.** Solved problems come back after 1, 3, 7, 14, 30 and 60 days. Re-solving a due problem counts as a review.
- **Dashboard.** Stats, current and longest streak, a 6-month activity heatmap, difficulty and topic breakdowns, a searchable problem log with notes, and CSV/JSON export and import.
- **Private by design.** Everything lives in `chrome.storage.local`. No accounts, servers, or analytics.

## Run it locally

1. Open `chrome://extensions` in Chrome (or any Chromium browser: Edge, Brave, Arc).
2. Turn on **Developer mode** (top-right).
3. Click **Load unpacked** and select this folder.
4. Pin LeetFocus from the puzzle-piece menu, then open a problem on leetcode.com and submit.

After editing code, click the ↻ reload button on the extension card and refresh any open LeetCode tabs.

## How it works

```
leetcode.com tab                                       extension
┌──────────────────────────────┐   postMessage   ┌──────────────────┐  sendMessage  ┌────────────────────┐
│ intercept.js (MAIN world)    │ ──────────────▶ │ bridge.js        │ ────────────▶ │ background.js      │
│ watches /submissions/…/check │                 │ + GraphQL meta   │               │ (service worker)   │
└──────────────────────────────┘                 └──────────────────┘               │ storage · alarms   │
                                                                                    └─────────┬──────────┘
                                                              popup (timer) & dashboard ◀─────┘ chrome.storage
```

- `src/content/intercept.js` wraps `fetch`/`XMLHttpRequest` in the page and reads the judge's final result for real submissions ("Run" is ignored).
- `src/content/bridge.js` tracks which problem is open, looks up title, difficulty and topics through LeetCode's GraphQL endpoint, and sends everything to the worker.
- `src/content/widget.js` renders the floating timer in a closed Shadow DOM, so page styles can't affect it. It only reads `chrome.storage` and sends commands; the worker stays the single source of truth.
- `src/background.js` owns all writes, including the Pomodoro state machine. It uses `chrome.alarms`, so the timer keeps running with the popup closed.
- `src/lib/storage.js` holds the shared data model and helpers.

## Project layout

```
manifest.json
icons/                  generated by scripts/make_icons.py
src/background.js       service worker: timer + tracking + data ops
src/content/            LeetCode page scripts (submission detection + floating timer)
src/popup/              toolbar popup (timer, today's stats, recent solves)
src/dashboard/          full dashboard (also the options page)
src/lib/                shared storage helpers + theme
```

## Publishing to the Chrome Web Store

1. Bump `version` in `manifest.json`.
2. Zip the extension, excluding dev files:
   `git archive -o leetfocus.zip HEAD manifest.json icons src`
3. Upload at the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole) (one-time $5 registration).
4. You'll need `icons/store-icon-512.png`, at least one 1280×800 screenshot, a short description, and a privacy statement. For the privacy statement, you can say that all data is stored locally and nothing is collected or transmitted.
5. Permission justifications: `storage` (saving progress), `alarms` (Pomodoro timer), `notifications` (phase-end alerts), and the content script on leetcode.com (detecting accepted submissions).
